# 个人技能仓库

这个仓库用于存放个人技能（skills），每个文件夹代表一个独立的技能。

## 技能列表

| 技能名称 | 描述 |
|---------|------|
| [wangshen-filler](./wangshen-filler) | 网申表单填写全流程（快速版）。自动打开网申页面、提取待填字段、从信息库取值、批量填写表单，支持多步表单和附件上传，全程不点保存/提交按钮。 |

## 如何添加新技能

每增加一个技能，只需在上面的表格中添加一行，格式如下：

```markdown
| [技能名称](./技能文件夹名) | 技能描述 |
```

## 技能结构

每个技能文件夹通常包含：
- `SKILL.md` - 技能的主要说明文档
- 其他相关文件（如信息库、配置文件等）
